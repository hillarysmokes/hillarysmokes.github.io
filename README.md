# Hillary Smoke Portfolio

This repository contains the source for the personal portfolio website for Hillary Smoke, hosted at `https://hillarysmokes.github.io`.

## Overview

This project is a static single-page website built with plain HTML, CSS, and a small amount of JavaScript. It presents Hillary's professional profile, technical skills, entrepreneurial work, and contact information in a modern dark-themed portfolio layout.

## Project purpose

The site is designed to:

- introduce Hillary Smoke as an ICT professional and software developer
- highlight areas of expertise such as IT infrastructure, networking, software development, and digital entrepreneurship
- showcase selected projects and ventures
- provide a professional contact entry point for collaboration and business enquiries

## File structure

- `index.html` — main page structure and content
- `style.css` — all styling, layout, colors, responsiveness, and design elements
- `script.js` — small interactive behavior such as mobile navigation handling
- `README.md` — project overview and documentation

## Hosting

This repository is set up for GitHub Pages hosting. The site is published from the repository root and is available at:

- `https://hillarysmokes.github.io`

## Tech stack

- HTML5
- CSS3
- JavaScript
- GitHub Pages

## Notes

The site is primarily a personal branding and portfolio landing page rather than a typical application repository. It focuses on visual presentation and professional storytelling rather than backend functionality.
